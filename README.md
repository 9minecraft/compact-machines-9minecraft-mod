# Compact Machines — Build Factories Inside One Block

Compact Machines 9minecraft Mod lets you build an entire base inside one single block. This mod gives you a pocket dimension where each block holds a full room. You walk in, set up your farms or machines, walk out, and everything stays right where you left it. It helps you hide messy wires and save space by packing huge factories into a tiny area. You can even pick up the block and carry your whole workshop with you to a new location.

## What this build is

An unofficial rebuild of **Compact Mods**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
